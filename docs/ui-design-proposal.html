01统一自定义复选框与下拉选择框
深度清理 / AI 清理 / 应用卸载 / 构建清理
改造前（现状）
✓ 暗色下出现刺眼纯白方块
改造后（新设计）
暖炭底 + 陶土填充 + 居中对勾
做了什么调整 用纯 CSS 自定义复选框替代 WebKit 原生白底 checkbox，统一 5px 圆角、陶土色选中态与居中矢量对勾（自动适配 13px/15px/16px 尺寸）；AI 工具筛选下拉框改为自定义单线 chevron 箭头与 8px 圆角。
为什么这样调整 当前暗色模式下原生纯白复选框是整个界面最强烈的视觉噪点，且与空间分析里的自定义 .pick 风格割裂；统一控件语言后，四张核心清理页的精致度会立刻跃升一个台阶。

05统一圆角阶梯、顶部 1px 微高光与状态监控升级
全局容器、顶部工具栏、状态监控、空间分析
改造前（现状）
• 状态页指标卡圆角 8px，同页下方进程面板 12px，几何不统一
• 搜索框圆角 6px，紧挨着的按钮 8px
• 空间分析暗色选中描边用纯白 #fff 偏刺眼，子格 2px 直角
• 模态框背景模糊 5px，层次偏薄
改造后（新设计）
• 全站严格统一圆角阶梯：大面板/指标卡 12px、按钮/搜索框/下拉框 8px、小控件 5px
• 卡片与按钮增加极克制顶部 1px 微高光（模拟实体金属面板受光边）
• 空间分析选中描边改为柔和暖白 rgba(255,250,240,0.9)，子预览格圆角 5px
• 状态页补齐柔和面积微折线、四段式内存条、38px 进程行高；弹层模糊升级 8px
做了什么调整 统一全站几何圆角与间距刻度，收紧大号等宽数字字距（-0.03em），并给状态监控与空间分析注入克制的数据视觉层次。
为什么这样调整 精致感来自“细节的一致性”：当相邻控件的圆角、高度、描边和光影逻辑完全统一时，整个应用会自然呈现出原生 macOS 专业工具的高级感。
